# Теллерийн систем

Систем маань дараах 4 үндсэн хэсгээс бүрдэнэ:

## 1. Бүрэлдэхүүн хэсгүүд

| Нэр | Файлын нэр | Тайлбар |
|---|---|---|
| Дугаар олгогч | `NumberDispenser.WinForms` | Банкны үүдэнд байрлах терминал. Харилцагч оочероо авна, сервер тэр дугаарыг бүртгэнэ. |
| Теллер апп | `TellerApp.WinForms` | Теллерийн ашиглах апп. 3 үндсэн үйлдэлтэй: **дараагийн үйлчлүүлэгчийг дуудах**, **мөнгөн гүйлгээ хийх** (данснаас данс руу), **валютын ханш өөрчлөх**. |
| Валютын ханш харуулах дэлгэц | `CurrencyBoard.Blazor` | Веб апп. Теллер ханш өөрчлөх тутамд realtime өөрчлөгдөнө - дэлгэц refresh хийх шаардлагагүй. |
| Сервер | `BankServer.API` | Дээрх бүх хэсгийг холбож өгдөг WebAPI + SignalR + дараалал бүхий сервер. |
| Unit test| `BankServer.API.Tests` | Unit тестүүд |
 
Эдгээрийг холбосон нэг санг (`BankServer.Shared`) бүх апп ашигладаг тул мэдээлэл (DTO)
хоорондоо давхцахгүй.

## 2. Ашигласан технологи

- **.NET 10 / ASP.NET Core** - WebAPI
- **SignalR** - realtime холболт (socket сервер-ийн үүрэг гүйцэтгэнэ)
- **`System.Threading.Channels`** - зэрэг ирсэн хүсэлтүүдийг дараалалд оруулж, нэг дугаарыг
  давхар дуудах, гүйлгээг давхар хйихээс сэргийлнэ
- **PostgreSQL** - өгөгдлийн сан (ORM ашиглаагүй, `Npgsql`-аар шууд SQL бичсэн)
- **Blazor Server** - валютын ханш харуулах веп аппд ашигласан
- **WinForms** - Дугаар олгогч, Теллерийн аппд ашигласан
- **Docker / docker-compose** - сервер, вэб апп, өгөгдлийн санг контейнерт асааж ажиллуулсан
- **xUnit + Testcontainers** - unit тестүүд дээр ашиглав.

## 3. Төслийн бүтэц

```
BankServer.API/              (solution: BankServer.slnx)
├── BankServer.API/          WebAPI + SignalR hub-ууд + Channel-дараалал
├── BankServer.Shared/       Бүх апп ашигладаг нийтлэг сан (DTO, hub contract, HTTP client)
├── NumberDispenser.WinForms/  Дугаар олгогч
├── TellerApp.WinForms/        Теллер апп
├── CurrencyBoard.Blazor/      Валютын ханшийн дэлгэц
```
